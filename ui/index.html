Exporter depuis Chrome

Chrome ne laisse aucun logiciel lire ses mots de passe directement (sécurité anti-vol). L'export, autorisé par toi, est la voie propre.

  1. Ouvre chrome://password-manager/passwords dans Chrome.
  2. Icône Paramètres, puis Exporter les mots de passe.
  3. Chrome demande ton code Windows, puis enregistre un fichier .csv.
  4. Reviens ici et choisis ce fichier.

Ce CSV est en clair. Supprime-le une fois l'import fait.
